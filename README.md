# sFun - SNES Emulator
Hello and welcome to sFun!
This is a long term project I plan to do to emulate Nintendo's SNES as a way to immerse myself into more systems programming and C++.
I want to be able to learn a lot from this project and documenting it will be important.
If you like this project I hope you can star it and look more into my socials!

Hope you have an awesome day.

## Current Status

- Register from 65816 CPU
- Status flags
- WRAM Mapping
- SDL2 Window (no rendering yet)

## How to Read the Code
1. `CPU.h / CPU.cpp` – CPU state, registers, reset, instruction fetch
2. `Memory.h / Memory.cpp` – Bus abstraction and memory map
3. `main.cpp` – Emulator entry point (temporary)
